# Button

Use a button for an action; one `inc-btn-primary` per view, for the thing the page or slide is for. The consumer provides a `<button>` or `<a>` with the classes and a sentence-case label that starts with a verb ("Book a call", "Download proposal").

- `inc-btn inc-btn-primary` – `action` orange fill (#C24C12), `on-action` white label (4.84:1). The main action. Darkens to `action-hover` on hover.
- `inc-btn` – secondary: `ink` (navy) outline and label on a light ground.
- `inc-btn inc-btn-quiet` – text-only action in `orange-text`, inside cards and tables.
- `inc-btn-accent` – older name for the primary button; it now looks the same. Use `inc-btn-primary` in new work.
- Add `inc-btn-sm` for 36px height in dense UI and tables.

Do: put the primary action first (left) in a row. Don't: use the bright logo orange (#EE5D10) or a gradient as a button fill, stack more than two buttons, or write labels in capitals.
