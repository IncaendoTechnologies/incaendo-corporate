# Callout

A short highlighted note: an assumption, a key benefit, a summary line under a process. The consumer provides `<div class="inc-callout">` with an `inc-callout-dot` span and the text, with the key phrase in `<strong>`.

- `inc-callout` – `orange-soft` with the key phrase in `orange-text`. The default, for the one thing the reader must not miss.
- `inc-callout-info` – `blue-soft`, for neutral information and assumptions.
- `inc-callout-orange` – older name for the default; it now looks the same.

One or two sentences, at most one callout per page or slide. Not for warnings about errors; use `Badge` status words for those.
