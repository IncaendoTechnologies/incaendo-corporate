# Badge

A badge labels a thing with one or two words: a technology, a status or a phase. The consumer provides a `<span class="inc-badge inc-badge-…">` and the text.

- `inc-badge` – neutral, for tech stacks ("React", "AWS", "Python").
- `inc-badge-brand` – `orange-soft` with `orange-text`: a phase or category ("Phase 2", "Food and retail").
- `inc-badge-orange` – solid `action` orange with a white label: "Recommended", "New". One per view.
- `inc-badge-blue` – info only.
- `inc-badge-success` / `-warning` / `-danger` – status, always with a word ("On track", "At risk", "Blocked"), never colour alone.

Sentence case, no icons, no more than five badges in a row.
