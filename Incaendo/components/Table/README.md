# Table

For commercials, timelines, responsibility matrices and data in proposals and product UI. The consumer provides a plain `<table class="inc-table">` with `<thead>`, `<tbody>` and optional `<tfoot>` for totals; add class `num` to amount cells.

- Header row on `orange-soft`, `body-strong`; alternate rows `surface-raised`; `line` dividers.
- Amounts right-aligned with currency and tax stated ("₹5,00,000 + GST").
- Keep to six columns; split wider tables. Status cells use `Badge`.
