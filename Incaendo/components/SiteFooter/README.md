# SiteFooter

The navy footer on every web page: the reversed logo with one line about Incaendo, two link columns (Services and Company), the contact column (legal name, Noida address, info@incaendo.com, LinkedIn, Instagram and Facebook), and a legal line with the copyright and policy links.

**The consumer provides** `<footer class="inc-footer">` inside an `inc-shell` wrapper, then `inc-container`, `inc-footer-grid` with `inc-footer-brand`, two `<nav aria-label>` columns (`inc-footer-heading`, `inc-footer-link`), `inc-footer-contact` with an `<address>` and `inc-footer-social` icon links (each with an `aria-label`), and `inc-footer-legal`.

**Layout:** four columns from 1024px; on phones the brand and contact blocks run full width and the two link columns sit side by side. Links grow to 44px tall on touch screens.

**Content:** use the registered name "Incaendo Technologies Private Limited", the Noida address and info@incaendo.com (sales@incaendo.com is for proposals only). Leave out the phone number until one is approved. Use the reversed logo only.

Do: keep each column to six links or fewer. Don't: add a newsletter form, awards or partner badges without approval.
