# CtaBand

A navy band near the end of a page that asks for one action: an `inc-cta-title` (with an optional orange `inc-highlight` phrase), one `inc-cta-text` sentence and up to two buttons: a primary "Book a call" and an `inc-btn-on-navy` outline (for example the email address).

**The consumer provides** `<section class="inc-cta-band">` inside an `inc-shell` wrapper, then `inc-container` and `inc-cta-inner` with the text block and `inc-cta-actions`. Text and buttons sit side by side from 1024px and stack below it.

Use it once per page, as the page's one navy emphasis band, usually just above the footer. Promise only what the team can keep: no response times or guarantees unless Santosh has approved them.

Do: say what happens next in plain words. Don't: add a third button, a form, or an orange background.
