# SectionHeader

The opening of a page section or a content slide: an orange `inc-eyebrow`, an `inc-section-title` that states the point, and an optional `inc-section-lead` line. The consumer provides the three texts inside `<div class="inc-section">`; add `<span class="inc-section-bar">` above the eyebrow on title-style slides.

Write the title as the takeaway ("Everything a doctor needs, in one screen"), not a label ("Features"). Eyebrow is one to three words. Lead is one sentence. Left-aligned only.


**On web pages** add `inc-section-web` (`<div class="inc-section inc-section-web">`, inside an `inc-shell` wrapper): the title becomes 28/36 on phones and 40/48 (`web-h2`) from 1024px, with section spacing below. Put one phrase of the title in `<span class="inc-highlight">` for a two-tone headline; one per section at most.
